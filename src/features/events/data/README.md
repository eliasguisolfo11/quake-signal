# Datos de continentes

El archivo continents.json contiene geometrías de países del dataset Admin 0 – Countries de Natural Earth a escala 1:110m, reducidas a geometría y nombre de continente para clasificar epicentros.

Fuente: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson

Natural Earth publica estos datos en dominio público. La geometría generalizada es adecuada para filtros por continente; no modifica ni reemplaza las coordenadas que reporta USGS.
